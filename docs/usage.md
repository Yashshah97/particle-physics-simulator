# Usage

```python
import particle_physics_simulator
```

Each module is self-contained; see docstrings for the API:

- `particle_physics_simulator.config` — Configuration management for simulation parameters
- `particle_physics_simulator.event` — Collision event data structure and manipulation
- `particle_physics_simulator.simulator` — Step-based simulator with configurable parameters
- `particle_physics_simulator.seed_manager` — Reproducible seed management for simulations
- `particle_physics_simulator.tests_test_config` — Unit tests for configuration management
- `particle_physics_simulator.core` — main domain logic and public entry points
